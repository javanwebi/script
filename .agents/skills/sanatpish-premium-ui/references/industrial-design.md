# Industry-specific content and imagery

- Scope visuals to the relevant product category and application. Belt families can include classical V A/B/C/D/E/Z/M, narrow SPA/SPB/SPC/XPA/XPB/XPC, timing XL/L/H and HTD 3M/5M/8M/14M, ribbed PK/PY/PL, polyurethane round and weldable profiles; verify live catalog records rather than treating examples as inventory.
- Industry pathways can include ceramic/tile, textiles, packaging, food/beverage, machinery, rubber/plastics; only link to routes actually present.
- Emphasize application, measurable technical fit, authentic product texture and user path to technical advice rather than ungrounded marketing copy.
- Use real Storage/API images with proper SKU associations; never silently reuse a sibling variant image and label it exact.
- Give designers page-specific content and visual briefs, not a universal homepage template.
