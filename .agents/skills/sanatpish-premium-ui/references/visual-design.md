# Visual design reference

- Audit existing tokens, logo, images and product taxonomy before changing composition.
- Start with the commercial task and identify a distinctive industrial concept: factory context, precision engineering, material/texture, mechanical rhythm or product detail.
- Build clear type hierarchy, deliberate whitespace, strong alignment, controlled accents and credible imagery. Avoid generic gradients, decorative blobs, oversized cards and repeated AI-style layouts.
- Primary orange #E06518, neutral #55565A, white; maintain sufficient contrast and use semantic rather than random colors.
- Design real hero imagery with believable equipment and actual product shapes; do not represent CSS rectangles as machinery. Keep text as accessible HTML rather than baking it into images.
- Produce purposeful section rhythm and informative product photography. Never invent labels, technical claims or SKUs.
